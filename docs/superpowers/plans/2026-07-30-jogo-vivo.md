# Jogo Vivo — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar o jogo-chave num jogo que se assiste lance a lance, com número variável de momentos (2–5) sorteados de um pool de situações, sem mexer na calibração.

**Architecture:** O engine (`src/engine/moments.ts`) passa a sortear quantos e quais momentos o jogo tem, com cada momento pesando `3/n` para manter `E[Σ deltas]` idêntico ao de hoje em qualquer contagem. `expectedAutoDelta` deixa de ser calculada fora e passa a ser calculada dentro de `startWatchedGame`, depois do sorteio. A UI (`src/ui/screens/Game.tsx`) ganha um cursor de reveal local que digita o log lance a lance e para quando chega no momento pendente.

**Tech Stack:** TypeScript, React 18, Vite, vitest, Playwright (e2e manual).

**Spec:** `docs/superpowers/specs/2026-07-30-jogo-vivo-design.md`

## Global Constraints

- `src/engine/` é TS puro: sem React, sem localStorage, sem `Math.random`. Toda aleatoriedade via `Rng` injetado.
- Toda string visível ao usuário passa por i18n (`src/data/i18n/pt.json` + `en.json`, paridade de chaves testada). Nunca hardcodar texto em componente.
- **Não mudar a forma** de nenhuma fórmula de `src/engine/season.ts` nem os pesos/thresholds de `src/engine/verdict.ts`. Constantes que ficam intocadas neste ciclo: `MARGIN_NOISE = 16`, `SERIES_SHIFT = 0.20`, `PLAYER_OUT_MARGIN`, a tabela `RISK` (base/attrW/hit/miss), `ICONIC_VALUES`, o gate do GOAT.
- Sem fotos/logos reais de NBA — nomes ok.
- Antes de cada commit: `npm test` e `npx tsc -p tsconfig.app.json --noEmit`.
- **Flake conhecido:** a primeira run do vitest depois de `npm install` ou de criar worktree pode falhar com "no tests" — re-rodar. `tests/engine/calibration.test.ts` também tem flake de timeout intermitente (débito no HANDOFF).
- Save key final deste ciclo: `thegoat:v6`.
- Peso por momento: `3 / n`, onde `n = moments.length`. Aplicado ao delta em **todo** lugar que soma deltas (margem, `playerPts`, `expectedAutoDelta`, placar do log). Nunca somar `o.delta` cru.

```ts
const CLUTCH_AT = 47.65
const FIRST_AT = 10

// Base pelo peso do jogo. `elimination` NÃO entra: playoffContext o marca true em todo
// jogo de rounds 0-2, então a distinção útil é kind (playoff = rounds 0-2, finals).
function baseCount(kind: WatchedGameKind): number {
  if (kind === 'finals') return 5
  if (kind === 'playoff') return 4
  return 3
}

export function momentCount(context: WatchedGameContext, rng: Rng): number {
  return clamp(baseCount(context.kind) + rng.int(-1, 1), 2, 5)   // 1 call
}

// n posições no relógio: a primeira em 10', a última sempre em 47.65' (4Q 00:21).
export function momentAts(n: number): number[] {
  return Array.from({ length: n }, (_, i) => FIRST_AT + (CLUTCH_AT - FIRST_AT) * (i / (n - 1)))
}

// Slots: os últimos n-1 de [openTone, q2tactic, q3swing, q4pressure], depois clutch.
function slotsFor(n: number): SlotKey[] {
  return [...SLOT_SEQUENCE.slice(0, 4).slice(-(n - 1)), 'clutch']
}

export function makeMoments(context: WatchedGameContext, rng: Rng): Moment[] {
  const n = momentCount(context, rng)                    // 1 call
  const ats = momentAts(n)
  return slotsFor(n).map((id, i) => {
    const s = rng.int(0, SITUATIONS[id].length - 1)       // 1 call por momento
    return {
      id,
      situationKey: `moment.${id}.s${s}`,
      at: ats[i],
      clock: clockOf(ats[i]),
      params: { opp: context.opponentTeamId.toUpperCase() },
      options: SITUATIONS[id][s],
    }
  })
}
```

```ts
export function resolveMoment(
  build: Build, age: number, option: MomentOption, weight: number, rng: Rng,
): { success: boolean; injury: boolean; delta: number } {
  const cfg = RISK[option.risk]
  const p = momentProb(build, age, option)
  const success = rng.chance(p)                          // call 1
  const injuryRoll = rng.next()                          // call 2 — SEMPRE consumido (contrato)
  const injury = option.injuryRisk !== undefined && injuryRoll < option.injuryRisk
  return { success, injury, delta: (success ? cfg.hit : cfg.miss) * weight }
}

// (playoffs): sem ela os momentos injetariam viés positivo na margem e a taxa de
// título estouraria o titleProb.
export function expectedAutoDelta(build: Build, age: number, moments: Moment[]): number {

    const o = defaultOption(m)
    const cfg = RISK[o.risk]
    const p = momentProb(build, age, o)
    return n + (p * cfg.hit + (1 - p) * cfg.miss) * w
  }, 0)
}
```

```ts
function logScore(baseMargin: number, deltas: number, at: number, jitter: number): { us: number; them: number } {
  const frac = at / 48
  const margin = baseMargin * frac + deltas + jitter
  const base = 100 * frac
  return { us: Math.max(0, Math.round(base + margin / 2)), them: Math.max(0, Math.round(base - margin / 2)) }
```

```ts
export function applyMoment(
  pending: PendingGame, option: MomentOption, build: Build, age: number, rng: Rng,
): PendingGame {
  const moment = pending.moments[pending.momentIndex]
  const w = momentWeight(pending.moments.length)
  const r = resolveMoment(build, age, option, w, rng)     // calls 1-2
  const outcome: MomentOutcome = {

  const outcomes = [...pending.outcomes, outcome]
  const deltas = outcomes.reduce((n, o) => n + o.delta, 0)
  const entry: PlayEntry = {

    params: { opp: pending.context.opponentTeamId.toUpperCase() },
```

```ts
export function finishWatchedGame(pending: PendingGame, build: Build, age: number): WatchedGameResult {
  const { context, outcomes, baseMargin, winP, expectedDelta } = pending
  const w = momentWeight(pending.moments.length)
  const margin = Math.round(baseMargin + outcomes.reduce((n, o) => n + o.delta, 0))
  const won = margin > 0
  const m = ageMultiplier(age, build.attributes.physical)
  const expPts = clamp((build.overall * m - 50) * 0.6, 6, 34)
  // pontos por acerto = impacto do RISCO daquela jogada, ponderado por 3/n: cinco
  // momentos não podem valer mais pontos que três (era o que carimbava closeout45).
  const playerPts = Math.round(clamp(
    expPts + outcomes.reduce((n, o) => n + (o.success ? RISK[RISK_OF.get(o.optionId) ?? 'safe'].hit : -2) * w, 0)
      + baseMargin / 8,
    6, 65,
  ))
  const injured = outcomes.some(o => o.injury)
  const clutchOutcome = outcomes[outcomes.length - 1]
  const choke = context.elimination === true && clutchOutcome !== undefined && !clutchOutcome.success && !won

  const iconics: IconicMomentId[] = []
  const clutchWinner = dagger({ outcomes }) && won && margin <= 4
  if (clutchWinner && context.kind === 'finals') iconics.push('finalsBuzzer')
  else if (clutchWinner && context.kind === 'playoff' && context.elimination) iconics.push('seriesWinner')
  else if (clutchWinner && context.kind === 'rivalry') iconics.push('rivalWinner')
  if (won && context.elimination && playerPts >= 45 && (context.kind === 'playoff' || context.kind === 'finals')) iconics.push('closeout45')
  if (won && outcomes.some(o => o.optionId === 'playHurt') && !injured) iconics.push('fluGame')
  if (won && baseMargin <= -15) iconics.push('comeback')
  if (playerPts >= 55 && (context.kind === 'rivalry' || context.kind === 'seedRace' || context.kind === 'special')) iconics.push('bigNight')

  const reb = Math.round(clamp((build.attributes.rebounding * m - 40) * 0.18 + margin / 12, 1, 22))
  const ast = Math.round(clamp((build.attributes.passing * m - 45) * 0.16 + margin / 15, 1, 18))
  return { won, margin, playerPts, reb, ast, outcomes, injured, choke, iconics, winP, expectedDelta }
}
```

```ts
import { useCallback, useEffect, useRef, useState } from 'react'

const CHAR_MS = 25
const LINE_PAUSE_MS = 600

// Quantas linhas do log podem aparecer antes de o painel de decisão abrir: todas as
// que acontecem ANTES do minuto do momento pendente. `stopAt = null` = jogo sem momento
// pendente (acabou), revela tudo.
export function revealTarget(ats: number[], stopAt: number | null): number {
  if (stopAt === null) return ats.length
  return ats.filter(at => at < stopAt).length
}

export function usePrefersReducedMotion(): boolean {
  const [reduced, setReduced] = useState(() =>
    typeof window !== 'undefined' && window.matchMedia('(prefers-reduced-motion: reduce)').matches)
  useEffect(() => {
    const mq = window.matchMedia('(prefers-reduced-motion: reduce)')
    const onChange = () => setReduced(mq.matches)
    mq.addEventListener('change', onChange)
    return () => mq.removeEventListener('change', onChange)
  }, [])
  return reduced
}

export function usePlayReveal(input: { texts: string[]; ats: number[]; stopAt: number | null }) {
  const { texts, ats, stopAt } = input
  const reduced = usePrefersReducedMotion()
  const target = revealTarget(ats, stopAt)
  const [shown, setShown] = useState(reduced ? target : 0)
  const [chars, setChars] = useState(0)
  const timer = useRef<ReturnType<typeof setTimeout>>()

  const skip = useCallback(() => { setShown(target); setChars(0) }, [target])

  // O log CRESCE quando um momento resolve, então `target` sobe e a digitação continua
  // sozinha nas linhas novas — `shown` nunca é reduzido, senão a decisão recém-tomada
  // sumiria da tela. Só o modo reduzido salta direto para o alvo.
  useEffect(() => { if (reduced) setShown(target) }, [target, reduced])

  useEffect(() => {
    if (shown >= target) return
    const full = texts[shown] ?? ''
    if (chars < full.length) {
      timer.current = setTimeout(() => setChars(c => c + 1), CHAR_MS)
    } else {
      timer.current = setTimeout(() => { setShown(s => s + 1); setChars(0) }, LINE_PAUSE_MS)
    }
    return () => clearTimeout(timer.current)
  }, [shown, chars, target, texts])

  return {
    shown,
    typing: shown < target ? (texts[shown] ?? '').slice(0, chars) : null,
    done: shown >= target,
    skip,
  }
}
```

```tsx
import { useEffect, useState } from 'react'

// Cronômetro do último lance. Não é animação decorativa: é gameplay, então
// prefers-reduced-motion NÃO o desliga — só o toggle timePressure desliga.
export function ClutchTimer({ ms, paused, onExpire }: { ms: number; paused: boolean; onExpire: () => void }) {
  const [left, setLeft] = useState(ms)
  useEffect(() => {
    if (paused) return
    const id = setInterval(() => setLeft(v => Math.max(0, v - 100)), 100)
    return () => clearInterval(id)
  }, [paused])
  useEffect(() => { if (left === 0) onExpire() }, [left, onExpire])
  return (
    <div className="clutch-timer">
      <div className="clutch-timer__bar" style={{ width: `${(left / ms) * 100}%` }} />
      <span className="mono clutch-timer__num">{(left / 1000).toFixed(1)}</span>
    </div>
  )
}
```

## Riscos de execução

- **Task 6, Monte Carlo de probabilidade-alvo:** se `|wins/runs − p| ≥ 0.04`, o peso `3/n` não está sendo aplicado em algum caminho (provável suspeito: `expectedAutoDelta` usando peso diferente do usado em `applyMoment`). Conferir que os dois usam `momentWeight(moments.length)` do mesmo `n`.
- **Task 8:** vermelho = parar e reportar ao dono, nunca ajustar constante de fórmula.
- **Task 9:** o `useEffect` que sincroniza `shown` com `target` é o ponto delicado — o log **cresce** quando um momento resolve, e `shown` nunca pode regredir (a linha da decisão recém-tomada sumiria da tela).
- **Task 9, decisão deliberada:** a fala do **último** lance (o clutch) não chega a ser digitada — `advanceGame` troca a fase para `gameResult` no mesmo dispatch. É intencional: o corte seco da decisão para a manchete de vitória/derrota é mais punchy do que ver o lance narrado e depois a manchete. A `GameResult` mostra o outcome do clutch na lista de decisões.
- **Task 12:** `node tests/e2e-playthrough.mjs` é manual e demorado; rodar uma vez só, no fim.
