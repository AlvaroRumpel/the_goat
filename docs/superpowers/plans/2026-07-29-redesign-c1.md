# Redesign C1 — Tema 2B + Barra de Carreira + Hub + Balanço Único Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aplicar o tema 2B "Jornal de Tinta Vermelha" ao app inteiro, adicionar barra de carreira + Hub, substituir o recap de 4 abas por balanço em tela única e redesenhar 8 telas estáticas — sem tocar no engine e sem bump de save.

**Architecture:** SPA React 18 + TS + Vite sem router; state machine única via `useReducer` em `src/App.tsx` (`gameReducer` em `src/state.ts`, persistência `localStorage['thegoat:v4']`). CSS puro global (`src/styles/tokens.css` + `base.css`), sem Tailwind/lib de UI. Cutover de tema em uma passada: primitivas novas com nomes semânticos + bloco COMPAT que mantém os seletores velhos renderizando o tema novo até a última task migrar `Game.tsx`/`Verdict.tsx` e apagar o bloco.

**Tech Stack:** React 18, TypeScript, Vite, vitest (só engine/state/data — UI não tem teste unitário), Playwright via `tests/e2e-playthrough.mjs` (manual).

## Global Constraints

- **Spec:** `docs/superpowers/specs/2026-07-29-redesign-c1-design.md`. Valores pixel/copy: `design_handoff_the_goat_redesign/README.md` (seções "Screens / Views" e "Design Tokens") + `design_handoff_the_goat_redesign/DECISOES-C1.md`. Copy PT dos arquivos de design é FINAL.
- `src/engine/` intocado — nenhuma linha muda em nenhuma task deste plano.
- Sem bump de save: chave continua `thegoat:v4`; campos novos são opcionais com default.
- Toda string visível passa por i18n (`src/data/i18n/pt.json` + `en.json`); paridade de chaves é testada (`tests/i18n.test.ts`). Nunca hardcodar texto em componente.
- Sem `Math.random` fora do engine; `NEW_GAME` continua com `seed: Date.now() % 2 ** 31` (único uso de relógio, já existente).
- Sem router, sem Redux/Zustand, sem biblioteca de componentes, sem Tailwind. Sem fotos/logos reais de NBA.
- `border-radius: 0` em tudo exceto `.mono-ring` (50%). Única sombra do app: `0 24px 60px rgba(20,18,14,0.45)` no cartão da encruzilhada.
- Antes de cada commit: `npm test` + `npx tsc -p tsconfig.app.json --noEmit` verdes.
- Alvo de toque mínimo 44px; corpo mínimo 12px; mono mínimo 9px.
